# Van Hair Academy — masterclass landing

A landing page for a hair academy that runs online and offline masterclasses on haircuts and colouring. It covers the course directions, the programme, the format, reviews, the instructor's bio and a sign-up form.

## Stack

Static site: HTML, CSS (`css/academy.css`) and vanilla JavaScript (`js/main.js`) — no build step.

`genkie/` contains helper scripts that generate the site's imagery through the Kie.ai API.

## Run locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```
